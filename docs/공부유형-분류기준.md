# 플잉 공부 유형 분류식 v1

## 발표에 쓸 설명

“설문 응답을 일곱 개의 지원 필요 지표로 바꾼 뒤, 미리 정의한 20개 유형의 기준값과 비교했습니다. 계획성과 실현성의 차이에 가장 큰 가중치를 주고, 가중 거리 합이 작은 세 유형을 추천합니다.”

## 응답에서 지표로

어려움 항목을 선택하면 1, 선택하지 않으면 0이다. A는 시작 순서, B는 계획 실천, C는 시간 부족, D는 휴식 부족, E는 어려운 과제 재시도다. F는 ‘일정이 밀리면 그날 계획을 놓아 버린다’에 그렇다고 답한 경우다. 학년과 직업은 분류에 쓰지 않는다.

| 지표 | 사용자 값 | 가중치 |
|---|---|---|
| 계획성 | 1 + 2A + C | 20 |
| 실현성 | 1 + 2B + C | 20 |
| 노력성 | 1 + 3E | 10 |
| 시간관리 | 1 + 2C + D | 15 |
| 자기조절 | 1 + 2D + C | 10 |
| 유연성 | 1 + 2F + C | 10 |
| 회복력 | 1 + 2F + B | 15 |

값의 범위는 1~4이며 클수록 해당 도움을 더 많이 요청한 패턴이다. 노력성은 어려운 과제의 재시도에 대한 자기보고로 해석한다.

## 가중 거리와 순위

유형 t의 거리 D(t) = Σᵢ wᵢ × |사용자 지표ᵢ − 유형 기준값ₜᵢ|. 가능한 범위는 0~300이다. 거리 오름차순으로 세 유형을 표시하고, 동점은 아래 표 순서를 따른다. 미응답 미리보기에서는 고정 예시 벡터 [3,4,2,3,2,4,3]에 같은 식을 적용한다.

계획 수립과 실천을 앱의 핵심으로 두어 각각 20을 배정했다. 하루 운영과 재시작에 해당하는 시간관리와 회복력은 각각 15, 나머지는 각각 10이다. 유형명과 강점 문구는 학습 코칭을 위한 디자인 가설이며 가중치와 기준값은 사용자 데이터로 검증하기 전의 초기 설정이다.

## 계산 예시

시간 부족(C)만 선택하고 마지막 문항에 ‘아니에요’라고 답하면 사용자 값은 [2,2,1,3,2,2,1]이다. 시간 수집가와의 거리는 0이다. 여백 건축가의 기준값 [2,2,1,4,4,2,1]과 비교하면 시간관리 차이 1과 자기조절 차이 2가 있어 거리는 15×1 + 10×2 = 35다.
