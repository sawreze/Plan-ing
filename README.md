# Plan-ing · 플잉

ADHD를 위한 다정한 일정·공부 메이트의 HTML 디자인 프로토타입입니다.

## 확인하기

`pling-app.html`을 내려받아 브라우저에서 열어 확인합니다. 이미지가 HTML에 포함되어 있어 파일 하나로 실행됩니다.

- `pling-app.html`: 로그인·설문·공부 유형·달력·집중·AI 채팅·목표·크루·설정 화면
- `pling-lockscreen.html`: 별도 잠금화면 일정 디자인 예시
- `HANDOFF.md`: 요구사항, 현재 구현 상태와 인수인계 명세서
- `pling-app-icon.png`: 선택된 앱 아이콘
- `pling-icons/`: 앱 아이콘 시안 4종과 제작 프롬프트
- `pling-mascot-pink-v3.png`: 현재 사용하는 핑크 짝꿍 캐릭터
- 기타 PNG·프롬프트 파일: 캐릭터 원본, 표정 및 제작 참고자료

## 최근 변경

- 앱 내부 라이트·다크·시스템 테마와 알림 설정
- 사각형 월간 달력과 날짜당 최대 3개의 계획 색깔 띠
- 설문 답변을 바탕으로 보여주는 공부 유형 사분면
- 사용자가 ▶를 눌러 시작하는 계획별 집중 타이머
- 완료 마스코트 애니메이션과 5코인 수령, 동일 계획 중복 수령 방지

일정·목표·코인·설정은 브라우저에 저장됩니다. 실제 로그인, Gemini API, 푸시 알림, 다중 사용자 크루 연결은 후속 개발 대상입니다.
