# Plan-ing · 플잉

ADHD를 위한 다정한 일정·공부 메이트의 HTML 디자인 프로토타입입니다.

- `pling-app.html`: 앱 디자인과 인터랙션. 파일을 브라우저에서 열어 확인합니다.
- `pling-lockscreen.html`: 별도 잠금화면 일정 디자인 예시.
- `HANDOFF.md`: 요구사항, 현재 구현 상태와 인수인계 명세서.

이미지는 HTML에 포함되어 있습니다. 일정·목표·코인·설정은 브라우저에 저장됩니다.
실제 로그인, Gemini API, 푸시 알림, 다중 사용자 크루 연결은 후속 개발 대상입니다.
